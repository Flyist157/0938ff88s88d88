# Testing Guide

## Automated Tests

There are currently no automated tests configured for this project.

## Manual Tests

1. Open `index.html` in a browser (or serve the folder with a static server).
2. In the hero section, toggle between "For pros" and "For customers" and
   confirm the headline, description, CTA labels, and badge update.
3. In "Lead inbox demo", accept and decline leads and confirm the counts and
   total due update correctly, then click "Reset demo".
4. In "Pros build profiles clients browse", edit the profile fields and verify
   the directory preview updates in real time.
